# DBM Supplies Docs

Guides and documents for the DBM Supplies team, shared publicly so anyone in the team can open them without a GitHub account.

## AP and AR user guide (17 Nov 2026)

How DBM Supplies' supplier bills (AP) and customer invoices (AR) work in the Accounts Portal: what the portal does for you, what you check, which button to press, who can do what, and what's still to be added.

| File | Best for |
|---|---|

| [DBM Supplies Bills and Invoices.html](AP-AR-User-Guide/DBM%20Supplies%20Bills%20and%20Invoices.html) | Download and open in a browser: the menu on the left stays on screen as you scroll. |

Questions: ask the portal team, with a screenshot of the bill or order.
